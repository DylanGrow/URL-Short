How do I create a GitHub Token?
  1. Go to your GitHub Developer Settings.
  2. Generate a **Fine-grained Personal Access Token**.
  3. Select **Only select repositories** and pick `URL-Short`.
  4. Under **Repository permissions**, set **Contents** to **Read and Write**.
  5. Click **Generate token** and copy it here.
